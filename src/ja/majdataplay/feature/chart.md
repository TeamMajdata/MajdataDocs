# 譜面

::: tip
MajdataPlay はオンライン譜面とオフライン譜面の両方に対応しています。オンライン譜面を推奨しており、MajdataProvider と組み合わせて使用できます。
:::

## オフライン譜面

[設定ファイル](/ja/majdataplay/configuration/)があるディレクトリには、`MaiCharts` フォルダーも含まれています。構造は次のとおりです。

```text
MaiCharts/
├── カテゴリ名/
│   ├── 曲名/
│   │   ├── maidata.txt
│   │   ├── track.ogg
│   │   └── bg.png
│   └── ...
└── ...
```
