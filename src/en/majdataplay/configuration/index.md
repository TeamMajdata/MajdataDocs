# Configuration file

::: tip
Run the game once before following this guide. Settings must be changed while the game is closed, so make sure it is not still running in the background.
:::

This page lists the location of the MajdataPlay configuration file on each platform. Other configuration guides assume that you have read this page.

## Windows

Open `settings.json` in the same directory as `MajdataPlay.exe`.

## iOS

<mark>You generally do not need to edit the configuration file manually on iOS. Open **Settings**, search for **MajdataPlay**, or select **Apps** in the sidebar and then select **MajdataPlay**. Almost every setting you need is available there.</mark>

To edit the file directly, open the **Files** app and select **On My iPhone** or **On My iPad**. Open the `MajdataPlay` folder, where you will find `settings.json`. You need a JSON editor to change this file; you can install an editor such as Koder from the App Store.

## Android

- APK version: `/storage/emulated/0/Documents/MajdataPlay/settings.json`
- Google Play version: `/storage/emulated/0/Android/data/net.majdata.majdataplay/files/settings.json`
