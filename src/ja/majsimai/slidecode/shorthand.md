# 展開と Simai 互換性

記述を簡単にするため、スライドコードでは**連続する同じ命令文字を省略できます**。パーサーが、命令文字が前にない数値パラメータを読み取ると、さかのぼって検索し、直近に現れた命令を使用します。

**例 1：**

* **完全形**：`5Q9A1P9P8CQ4Q9K5`
* **省略形**：`5Q9A1P98CQ49K5`
* **解析結果**：`(X)5 - Q9 - A1 - P9 - P8 - C - Q4 - Q9 - K5`
* *解説：先頭の `5` には前に文字がないため、技術的には開始命令 `X5` として解釈されます。`P98` の `8` にも前に文字がないため、パーサーはさかのぼって検索して `P` を見つけ、`P9 - P8` として解析します。`Q49` も同様です。*

**例 2：**

* **完全形**：`1P0P0P0P0P0K8`
* **省略形**：`1P00000K8`
* **完全展開**：`(X)1 - P0 - P0 - P0 - P0 - P0 - K8`
* *解説：省略規則を使えば、トラック命令で複数周する場合に `P, Q` を何度も書く必要はありません。実際、この省略規則はまさにこのために用意されたものです。*

**例 3：**

* **完全形**：`1A3A5A7K1`
* **省略形**：`1A357K1`
* **完全展開**：`(X)1 - A3 - A5 - A7 - K1`
* *解説：省略規則を使えば、A エリアの位置の間を行き来するパスを素早く書けます。*

## Simai との互換性

以上の例から、完全なスライドコードの文字列は必ず数字で始まり数字で終わることに気づくでしょう。標準の Simai のスライド構文も数字で始まり数字で終わります。そのため、Simai の譜面ファイルを書くときは、スライドコードの先頭と末尾の数字を除いた中間部分を、Simai における `<, >, p, q, pp, qq` のような形状文字列として扱い、スライドに標準の Simai の修飾を適用するだけで済みます。例えば `1bxA357K1b[2:1]` は、パスが `1A357K1`、星の頭が Break + EX、総長が 2 分音符 1 つ分の Break スライドを表し、とても分かりやすいです。同頭スライドも同じで、`*` で開始キーを置き換えます。

実際のところ、なぜそうするのかは不明ですが、スライドコードは標準のスライド構文と連結して連結スライドにすることもできます。例えば `1bA357K1>1[1:1]` は `1A357K1` と `1>1` を連結したものです。

> 見た目には、完全にスライドコードで記述したスライドと、標準のスライドとスライドコードを組み合わせた連結スライドには微妙な違いがあり、軌道上の矢印の位置が異なります。標準の Simai で `1-3-5[4:1]*V35[4:1]` のパスが完全に重なっていても、後半の矢印の位置が異なるのと似ています。視覚効果に極度にこだわる場面では、このテクニックが役立つかもしれません。
