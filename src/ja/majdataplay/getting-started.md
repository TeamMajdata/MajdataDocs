# 基本操作

ゲームを初めて起動すると、プログラムは[設定ファイル](/ja/majdataplay/configuration/)があるディレクトリに `settings.json` と `system-settings.json` を作成し、内蔵曲を展開します。[アーケードコントローラーの設定](/ja/majdataplay/configuration/external_device)を終えると、選曲画面からプレイを開始できます。

## アーケードコントローラーがない場合

アーケードコントローラーがなくても、キーボードとマウスでそのままプレイできます。

| 操作 | デフォルトの入力 |
| --- | --- |
| 8 つのボタン | `W` `E` `D` `C` `X` `Z` `A` `Q` |
| 1P 三角ボタン | テンキーの `*` |
| タッチ領域 | マウス |

キーボードの各キーは、ゲーム内の 8 つのボタンリングの位置に対応しています。アーケードコントローラーを使用する場合、ボタンとタッチはコントローラー側のデバイスから提供されます。

## 選曲画面

| 操作 | デフォルトの入力 |
| --- | --- |
| 難易度の切り替え | 1 / 8 番のボタン |
| 曲の切り替え | 3 / 6 番のボタン |
| ゲーム開始 | 4 番のボタン |
| 練習モードに入る | 4 番のボタンを長押しし、爆発音が聞こえたら離します |
| 戻る / アカウントからサインアウト | 5 番のボタン (オンライン時は長押しでサインアウトできます) |
| 設定を開く | 7 番のボタン |
| 並べ替え / 検索 | 2 番のボタンまたは 1P 三角ボタン |
| 楽曲ライブラリの更新 | 1P 三角ボタンを約 3 秒間長押し |

選曲画面では 1P 三角ボタンが並べ替え / 検索に使用されます。並べ替えや検索の画面では、キーボードの誤操作を防ぐため、画面をタッチして確定する必要があります。

## プレイ中

| 操作 | デフォルトの入力 |
| --- | --- |
| 楽曲を終了 | 1P 三角ボタン、または設定のサブ画面クリック動作に従います |
| 楽曲をスキップ | 2・3・6・7 番のボタンを押し続けます |
| クイックリスタート | 3・4・5・6 番のボタンを押し続けます |
| クイック練習 | 1・2・7・8 番のボタンを押し続けます |

スキップ、クイックリスタート、クイック練習は、いずれも `settings.json` の `Game` で対応する項目を有効にする必要があります。サブ画面のクリック動作は `Game.GameplaySubScreenClickBehavior` で制御します。

## 内蔵曲

インストーラーにはオリジナル / ライセンス許諾済みの楽曲が含まれており、`MaiCharts/Original` に配置されています。インストール後はそのままプレイできます。自作の譜面をインポートする方法は[譜面](/ja/majdataplay/feature/chart)を参照してください。

## オーディオの推奨設定

オーディオバックエンドは `system-settings.json` の `Audio.Backend` で設定します。遅延は低い順に、おおむね次のとおりです。

1. `"Asio"`: 最も低い遅延ですが、ASIO に対応したサウンドカードが必要です。一般的なサウンドカードでは [ASIO4ALL](https://asio4all.org/about/download-asio4all/) をインストールできます。
2. `"Wasapi"`: Windows で一般的なバックエンドです。排他モードは遅延が低いですが、OBS などのプログラムが同時に録音できなくなります。配信や録画を行う場合は `Audio.Wasapi.Exclusive` をオフにしてください。
3. `"BassSimple"`: BASS のデフォルトの出力方式で、互換性は比較的良好ですが、遅延が変動することがあります。
4. `"Unity"`: Unity 内蔵のオーディオで、予備の選択肢としてのみ用意されています。

音割れ、カクつき、音と映像のずれが発生する場合は、次の点を試してください。

- Windows のサウンドコントロールパネルで、すべてのサウンド効果をオフにし、アプリケーションによる排他制御を許可します。
- `Audio.Bass` のバッファーを適切に増やすか、`Rendering.FPSLimit` を下げます。
- ASIO を使用する場合は、ASIO コントロールパネルを開き、バッファーサイズを適切に調整します。
