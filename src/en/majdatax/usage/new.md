# Create a chart

## Create from `track.mp3`

This is the original and most common method. On the **Start Page**, or under **File > New**, select a `track.mp3` file to create a chart.

## Create from a video

This newer workflow saves several preparation steps. A typical charting workflow starts by downloading a music video, adjusting its duration, extracting its audio, and finally creating a chart from `track.mp3`.

Now you can select a video on the **Start Page** or under **Tools > Create Chart from Video**. MajdataEdit handles everything except trimming the duration. The **Chart Information** window opens automatically so you can enter the chart's basic information and finish the initial setup.
