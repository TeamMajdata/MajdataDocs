# はじめに

## 概要

![MajdataX のインターフェース概要](/majdatax/index/overview.png)

初めて MajdataX を開いたときは、パネルが散らばっているため、このような見た目にならない場合があります。一度配置とサイズを調整してください。MajdataX はレイアウトを保存し、次回起動時に復元します。

MajdataX は、高速で高機能な譜面編集体験を提供することを目的として設計されています。

::: tip
音声や動画の機能を使用する前に、ターミナルを開いて `winget install ffmpeg` を実行し、FFmpeg をインストールしてください。
:::
