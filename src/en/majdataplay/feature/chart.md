# Charts

::: tip
MajdataPlay supports both online and offline charts. Online charts are recommended and can be used together with MajdataProvider.
:::

## Offline charts

The directory that contains the [configuration file](/en/majdataplay/configuration/) also contains a `MaiCharts` folder. It uses the following structure:

```text
MaiCharts/
├── Category name/
│   ├── Song name/
│   │   ├── maidata.txt
│   │   ├── track.ogg
│   │   └── bg.png
│   └── ...
└── ...
```
