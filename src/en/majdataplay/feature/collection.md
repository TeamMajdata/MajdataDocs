# Playlists

::: tip
This feature requires **Online** to be enabled and uses the MajdataNet service.
:::

If you are not sure what to play, or keep forgetting the charts you enjoyed, use a playlist (also called a collection) to save them.

## Online playlists

[Enable **Online**](/en/majdataplay/configuration/online).

[Read the MajdataNet playlist guide](/en/majdatanet/feature/collection).
