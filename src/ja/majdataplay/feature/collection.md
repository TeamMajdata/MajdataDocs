# プレイリスト

::: tip
この機能を使用するには **オンライン** を有効にする必要があり、MajdataNet サービスを利用します。
:::

何をプレイするか迷っているときや、楽しかった譜面をいつも忘れてしまうときは、プレイリスト（コレクションとも呼ばれます）に保存しておきましょう。

## オンラインプレイリスト

[**オンライン** を有効にする](/ja/majdataplay/configuration/online)。

[MajdataNet のプレイリストガイドを読む](/ja/majdatanet/feature/collection)。

プレイリストの JSON ファイルを手動で作成することもできます。詳しくは[プレイリストファイル](/ja/majdataplay/feature/dan#playlist-files)を参照してください。
