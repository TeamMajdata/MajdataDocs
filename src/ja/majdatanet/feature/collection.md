# プレイリスト

~~この機能は名前が一つに定まらなかったため、「プレイリスト」と「コレクション」はどちらも同じものを指します。~~

## はじめに

自分だけのプレイリストを作成することも、ほかの人が公開しているプレイリストをプレイすることもできます。<mark>プレイリストは購読しないとゲーム内に表示されません。</mark>

1. [MajdataNet](https://majdata.net) を開き、アカウントを登録してサインインします。
2. プレイリストを作成するには、次の手順に従います。
   1. 追加したい曲のページを開きます。
   2. 左側の **お気に入り** をクリックします。
   3. **新しいコレクション** をクリックします。
   4. **名前** を入力し、公開範囲を選択します。

      ::: tip
      ほかの人にもプレイしてもらいたい場合は **公開** を選択してください。自分だけで使う場合は **非公開** を選択してください。
      :::

   5. **作成** をクリックします。
   6. コレクションが作成されたら、それをクリックして現在の曲を追加します。
3. ほかの人が公開しているプレイリストをプレイするには、次の手順に従います。
   1. ナビゲーションバーから **プレイリスト広場** を開きます。
   2. プレイリストカードの右上にあるハートをクリックして購読します。
4. ナビゲーションバーのアカウントメニューから **マイコレクション** を開きます。
5. **購読中のプレイリスト** に並んでいるプレイリストが、ゲーム内に表示されます。
