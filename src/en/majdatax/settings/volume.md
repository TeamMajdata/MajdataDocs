# Volume settings

| Sound file | Sound type |
| --- | --- |
| `track_start.wav`, `all_perfect.wav` | Track |
| `answer.wav`, `answer_clock.wav` | Answer |
| `tap_perfect.wav`, `tap_great.wav`, `tap_good.wav`, `tap_ex.wav` | Tap |
| `break_tap.wav`, `break.wav` | Break |
| `slide.wav` | Slide |
| `slide_break_start.wav`, `slide_break_slide.wav` | BreakSlide |
| `touch.wav`, `touch_Hold_riser.wav` | Touch |
| `touch_hanabi.wav` | Hanabi |

Your `track.mp3` also uses the **Track** volume.
