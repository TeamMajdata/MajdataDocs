# 自動保存を復元する

## 自動保存の復元パネルを開く

**スタートページ**、または **ファイル > 自動保存の復元** から自動保存の復元パネルを開きます。

![自動保存の復元パネル](/majdatax/usage/recovery/panel.png)

左上で復元したい自動保存を選択します。左下のコントロールで対応する難易度の行に移動できます。内容を確認したら **復元** をクリックします。**開く** をクリックして対応する譜面ファイルを直接開くこともできます。現在開いている譜面を復元した場合、MajdataX は自動的にそれを再読み込みします。

**復元はファイル全体を置き換えます。難易度ナビゲーションは内容を確認するためのものにすぎません。**
