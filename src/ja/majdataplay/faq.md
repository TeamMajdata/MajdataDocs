# よくある質問

このページでは、よくある質問をいくつかまとめています。

## OBS で MajdataPlay の音声を録音できないのはなぜですか？ なぜ MajdataPlay が他のアプリの動画・音声の再生を妨げるのですか？

> 設定で MajdataPlay の音声の排他モードをオフにしてください。

## 音声の再生が始まらない、または音が出ない場合はどうすればよいですか？

1. Windows のサウンド コントロール パネルですべてのサウンド拡張を無効にします。
2. アプリケーションによる排他制御を許可し、排他モードを優先に設定します。
3. `system-settings.json` で `Audio.Backend` を切り替えるか、`Audio.Bass` のバッファーを適切に大きくしてみてください。

## CPU 使用率が高すぎてフレームが落ちる場合はどうすればよいですか？

入力デバイスの `PollingRateMs` を適切に大きくして (例: `2`)、ポーリング頻度を下げることができます。ただし、判定が悪化する可能性がある点に注意してください。

## GPU 使用率が高すぎてフレームが落ちる場合はどうすればよいですか？

1. グラフィックスドライバーのコントロール パネルで MajdataPlay のグラフィック設定を調整します。
2. `Rendering.RenderQuality` を下げるか、`"Custom"` を使用して `Rendering.RenderScale` を下げます。
3. `Rendering.CompatibilityMode` を有効にしてみてください。

## ゲームウィンドウを別のディスプレイに移動するには？

> `Alt` + `Enter` キーを同時に押して全画面表示を解除し、マウスで目的のディスプレイにドラッグしてから、もう一度 `Alt` + `Enter` キーを同時に押して全画面表示に戻します。

## MajdataPlay のログを確認するには？

1. [設定ファイル](/ja/majdataplay/configuration/) があるフォルダーを探します。
2. その中の `Logs` フォルダーを開きます。
3. テキストエディターで `MajPlayRuntime.log` ファイルを開きます。

## その他の問題が発生した場合はどうすればよいですか？

1. MajdataPlay の QQ 交流グループ `667644338` に参加します。
2. 発生した問題を説明します (<mark>できるだけ詳しく</mark>)。
3. ログファイルをアップロードします。
4. グループのメンバーからの回答を気長に待ちます。
