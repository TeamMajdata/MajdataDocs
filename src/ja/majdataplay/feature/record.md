# ゲームプレイを録画する

::: warning
この機能はモバイルデバイスでは使用できません。
:::

## OBS を設定する

MajdataPlay が OBS の録画ショートカットを代わりに操作します。まず OBS でシーンを設定し、MajdataPlay を<mark>ディスプレイキャプチャまたはゲームキャプチャ</mark>でキャプチャしてください。他のキャプチャ方法では動作しない場合があります。

![OBS WebSocket の設定](/majdataplay/feature/record/obs_configuration.png)

1. OBS 上部の **ツール** を選択します。
2. **WebSocket サーバー設定** を選択します。
3. **WebSocket サーバーを有効にする** をオンにします。
4. **サーバーポート** を `4455` に設定し、**認証を有効にする** をオフにします。

## MajdataPlay を設定する

録画オプションを `OBS` に設定します。

## 録画状態を確認する

接続に成功すると、プレイ開始後にサブディスプレイのマスコットの下にカメラアイコンが表示されます。アイコンは次のいずれかの状態を示します。

- **OBS 未準備**：MajdataPlay が OBS に接続されていません。
- **OBS 準備完了**：MajdataPlay が接続され、録画の準備ができています。
- **OBS 録画中**：OBS が現在のプレイを録画しています。
