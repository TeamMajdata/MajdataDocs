# 譜面作成前のメディア準備

::: warning
このページのツールを使用する前に、ターミナルを開いて `winget install ffmpeg` を実行し、FFmpeg をインストールしてください。
:::

## 長さを調整する

### 先頭に 1 小節の無音を入れる

譜面のオフセットを変更するよりも、最初の拍がちょうど開始から 1 小節後に始まるように音声を調整するほうが一般的に望ましいです。これには **ツール > メディアのクイック処理** を使用します。

まず、ツールが開始 BPM を読み取れるように、譜面に `(bpm){1},` を追加します。下の波形で、**最初の**黄色い線を音声の最初の拍に合わせます。表示されるパネルで、追加する拍数を入力し、長さが不足する場合に最初の動画フレームを固定するかどうかを選択します。このオプションがオフの場合、MajdataX は追加された長さを黒フレームで埋めます。その後 **確認** をクリックします。

この処理には時間がかかる場合があります。

::: tip
信頼できる手順は次のとおりです。

1. BPM がわからない場合は、画像に示されている **BPM 検出** に合わせてタップし、おおよその値を得ます。
2. BPM がわかったら、`(bpm){4}1,1,1,1,1,1, ...` のようなテストパターンを入力して、BPM とオフセットを検証します。
3. **ツール > メディアのクイック処理** を実行します。処理が完了したら、テストパターンを削除します。
:::

### 曲をトリミングする

<mark>MajdataX には現在、曲をトリミングするツールがありません。</mark> 音楽動画をダウンロードした後、`ocenaudio` などの音声エディタでトリミングしてください。その後 MajdataX で開き、先頭に 1 小節の無音を追加します。

## 動画を圧縮する

上記のように、**ツール > 背景動画を圧縮** で背景動画を直接圧縮できます。元の動画が異常に大きくない限り、結果は MajdataNet の 20 MB 制限以下に収まるはずです。

この処理には時間がかかる場合があります。
