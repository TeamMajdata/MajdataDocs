# Introduction

## Overview

![MajdataX interface overview](/majdatax/index/overview.png)

The interface may not look like this when you open MajdataX for the first time because the panels may be scattered around. Arrange and resize them once; MajdataX saves the layout and restores it the next time you open the app.

MajdataX is designed to provide a fast, capable chart-editing experience.

::: tip
Before using audio or video features, open a terminal and run `winget install ffmpeg` to install FFmpeg.
:::
